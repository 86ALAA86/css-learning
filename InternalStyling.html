This is the lesson where i will use Internal Styling :

Inline styling

inline styling is a way to apply some apperance modifications on the element it self . for example you can add colors , font type , size ,borders ,marging .....

Internal styling

internal styling is a way to apply some apperance modifications on the element and all other element from the same type without repeating the style in every each one of them. for example you can add colors , font type , size ,borders ,marging .....
